# Mynavi 2027 Company Blocker

マイナビ就活の検索結果ページで不要な企業を非表示にできるTampermonkeyスクリプトです。  
A Tampermonkey userscript that hides unwanted companies on Mynavi job search pages.

---

## 🚀 Features / 機能

- 「今後表示しない」ボタンで企業を非表示にできます  
  Hide companies using the “Don’t show this company again” button

- 非表示状態を自動保存  
  Hidden companies are saved automatically

- マイナビ検索ページに対応  
  Works on Mynavi job search result pages
